# Third-Party Components

This repository contains code derived from or adapted from existing
open-source projects.

## M3DM

PAS is implemented on top of the M3DM framework for multimodal 3D anomaly
detection.

The M3DM-derived portions of this repository retain the original MIT License
and copyright notice:

Copyright (c) 2023 nomewang

PAS-specific implementations, modifications, experimental scripts, sampling
strategies, prior-guided center selection, and coverage-aware calibration were
developed as part of this project.

## Other Dependencies

This project also uses or may depend on third-party implementations and
pretrained models including:

- DINOv2
- Point-MAE
- PointNet++
- DGCNN

terms of use.
